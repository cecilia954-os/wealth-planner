# 财富规划助手 · 对话式原型 V0.1

按《理财师平台财富规划 PRD V0.3》实现的第一版可运行原型：

**对话采集 → 集中确认 → 确定性测算 → 结果页 / 建议书**

无需后端、无需安装依赖，所有数据留在浏览器本地。

## 打开方式

- 直接双击 `index.html`；或
- 在本目录执行 `python -m http.server 8765`，访问 <http://localhost:8765>

推荐使用 Edge / Chrome。下载 Word 和打印 PDF 在本地文件或本地服务器下均可用。

## 快速体验

1. 右上角选择客户（张伟 / 李娜 / 王强 / 陈建国）。
2. 在对话卡片中勾选规划目标，点击「开始规划」。
3. 按助手提问回答：可直接输入自然语言（如「月薪2.5万」「每月8000」「3年后」），也可点击快捷选项。
4. 问答完成后点击「集中确认」，核对客户提供值、画像带入值、系统默认值和经理修改值。
5. 确认后查看：摘要、逐年现金流、购房、教育、养老、建议书。
6. 建议书支持「下载 Word」和「打印 / PDF」。

想直接看结果，点击右上角「载入示例方案」。也可以用 URL 直达某个结果页：

```text
index.html?demo=1&tab=summary
index.html?demo=1&tab=years
index.html?demo=1&tab=housing
index.html?demo=1&tab=education
index.html?demo=1&tab=retirement
index.html?demo=1&tab=proposal
```

## 已实现范围

### 对话与输入
- 客户 360 画像、目标多选、按目标动态提问、条件分支（贷款/全款、是否出国、是否已退休、是否参加职工养老）。
- 自然语言金额解析：万/万元/元/千元、月薪/每月/每年、百分比、年份、年级、教育阶段等。
- 每个字段标注来源：画像带入 / 客户提供 / 系统默认 / 经理修改。
- 集中确认页集中展示与编辑全部字段；任何修改都会重新测算。
- 同一客户重新进入时，从本机浏览器恢复上次已采集会话（含已确认/待确认状态）。

### 计算
- 统一年度账本：P0、年度收入/支出、净结余、累计净结余、年末余额。
- 投资计划：1.5% 年度增长、医疗按年龄/收入档/城市档匹配、赡养支出。
- 购房：全款/贷款、首付、等额本息月供、购房当年 12 期、后续年度还款、期末剩余贷款本金。
- 教育：国内/海外、城市档/路线、当前年级逐年推进、每年 1.5% 增长、同一孩子同一年只取一条预算。
- 养老：职工基本养老金公式、个人账户倒推与逐年缴费、计发月数、最低缴费年限校验、已退休/未参保/缴费不足分支。
- 汇总：期末目标缺口/富余、首次资金不足年份、最大年度资金不足、需追加初始资金。
- 校验与异常：医疗参数缺失显示「待配置」并锁建议书；教育年龄冲突提示；缴费年限不足不自动生成正常领取结论；购房年份越界阻止测算；修改输入后重新测算。

### 输出
- 结果摘要卡片、逐年现金流表（18 列）、购房/教育/养老明细。
- 可核对的财富规划建议书（结论摘要、客户需求、输入与假设、逐年现金流、各目标规划、缺口建议、复盘安排、风险提示）。
- Word `.doc` 下载、浏览器打印 / 另存 PDF。

## 演示参数（非正式业务口径）

| 参数 | 本版取值 |
| --- | --- |
| 通用增长率 | 1.5%/年 |
| 购房默认 | 首付 30%、30 年、等额本息、年利率 3.5% |
| 教育预算 | PRD 6.3 / 6.4 的万元/年数值 |
| 医疗预算 | 演示表：城市档 × 收入档 × 年龄档 |
| 各城市月社平工资 | 一线 12,183 / 二线含新一线 9,000 / 三四线 7,000 元 |
| 个人账户 | 计入 8%、记账利率 1.5% |
| 养老金缴费指数 | 1.0，缴费基数 = 当地社平工资 100% |
| 计发月数 | 40–70 岁常用标准表 |
| 最低缴费年限 | 2026–2029 年 15 年；2030 年起每年 +0.5 年，2039 年 20 年 |

页面和报告均展示「演示参数 v0.1（2026-11）」。正式上线前，医疗、教育城市映射、各城市社平工资、计发月数、最低缴费年限、贷款默认值和所有增长率需接入后台参数服务并做版本管理。

## 本版未实现 / 简化

- **自然语言理解目前是规则解析 + 快捷选项**，尚未接入真实大模型。PRD 中「大模型负责理解自然语言、决定下一轮问题」可在下一步替换 `app.js` 的解析层，计算层不需要改。
- 未接入真实登录、服务端存储、客户 360 接口；客户画像为演示数据。
- PDF 通过浏览器打印生成，未做服务端 PDF 渲染。
- 按 PRD 第一版边界，不计算投资收益/复利/折现，不做资产配置和产品推荐，不采集保险费用，不自动测算城乡居民养老和职业年金，不处理提前还贷、组合贷、税费、装修及月内到账顺序。
- 海外预算按 PRD 只覆盖高中/本科/研究生；最高阶段低于高中时不出国。
- 养老金最低缴费年限为演示口径，需按正式政策参数替换。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构（客户画像 / 问答区 / 测算结果 / 确认与结果弹层） |
| `styles.css` | 视觉样式与响应式布局 |
| `data.js` | 客户画像、演示参数、教育/医疗/养老金参数表 |
| `engine.js` | 确定性计算引擎（可在 Node 中独立测试） |
| `app.js` | 对话状态机、自然语言规则解析、确认页、结果页、建议书、会话恢复 |
| `test-engine.js` | 计算引擎自测：`node test-engine.js` |
| `drive-test.js` | 用 Edge DevTools Protocol 驱动完整问答与结果校验；需本机 Edge |

### 校验命令

```bash
node test-engine.js                 # 计算场景
node drive-test.js zhangwei         # 贷款购房 + 教育 + 养老 + 全款切换 + 会话恢复
node drive-test.js lina             # 未参加职工养老 + 缴费不足 + 海外教育
node drive-test.js retired          # 已退休客户 + 当前养老金
```

`drive-test.js` 会启动无头 Edge，仅在调试端口 `9333` 运行，不访问网络。测试截图写入系统临时目录 `wealth-planner-shots`。
